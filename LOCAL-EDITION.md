# Edição local do Sonora

Esta pasta pode ser executada diretamente no Windows sem publicar no GitHub. Instale Python 3, execute `iniciar.bat` e use o endereço `http://127.0.0.1` que aparecer no terminal. O site e os dados ficam no computador; a busca musical online continua exigindo internet.

A edição local não é um executável `.exe`: é o mesmo aplicativo web servido localmente, para usar com mais privacidade e sem depender do GitHub Pages. A janela do terminal precisa permanecer aberta enquanto o site estiver em uso.
