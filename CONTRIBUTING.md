# Como contribuir

1. Faça um fork do repositório.
2. Crie uma branch para a sua alteração.
3. Mantenha o projeto em HTML/CSS/JavaScript simples, sem adicionar segredos ou credenciais.
4. Execute `node --check app.js` para validar a sintaxe.
5. Teste as telas principais no navegador, incluindo conta nova, login, importação de música, busca online e edição de um rascunho de Reel.
6. Abra um pull request descrevendo o que mudou e como testou.

Não envie arquivos pessoais, vídeos, músicas protegidas ou dados do cofre ao repositório.
