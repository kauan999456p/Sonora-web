# Protótipo: Sonora Reels Studio

Status: **inacabado / experimental**.

Objetivo: transformar rascunhos em projetos de vídeos verticais curtos. A versão integrada no Sonora já oferece título, descrição, etapa, progresso, vídeo local e pré-visualização básica.

Ainda faltam: linha do tempo com múltiplas cenas, corte de trechos, capas personalizadas, legendas editáveis, transições, exportação MP4 e sincronização com conta online.

Os rascunhos são locais e não são publicados automaticamente.
